# Portfolio Website Plan

## Purpose

Build a professional, clean, and visually polished portfolio for a computer science student. The site should help potential collaborators and internship teams quickly understand the work, interests, and ways to get in touch.

## Profile and content

- Software engineering is the foundation.
- Include networking experience and growing interests in data science, machine learning, and AI.
- Showcase completed Flutter apps, Django apps, and other web projects.
- Projects still being developed may be included with their status made clear.
- Use placeholder content while building; add and refine real project details once the site is running.

## Experience and structure

- Project-first homepage with a concise introduction and featured work.
- Project cards link to fuller project write-ups when useful.
- Skills are grouped by area rather than presented as an unstructured list of badges.
- Include a short about section and clear links for GitHub, LinkedIn, résumé, and contact.
- Responsive layout that works well on phones, tablets, and desktops.

## Visual direction

- Blend a dark, technical hero section with clean, light content sections.
- Use crisp typography, generous spacing, restrained color accents, and subtle technical details.
- Keep motion purposeful and restrained; respect reduced-motion preferences.
- Prioritize readability, clear navigation, keyboard use, and accessible color contrast.

## Technology and scope

- Build the first version with Astro and TypeScript as a static site.
- Use semantic HTML, responsive CSS, and only the JavaScript needed for useful interactions.
- No backend in the first version. Keep the structure easy to extend with a backend later.
- Include basic metadata and search previews, and keep pages lightweight.

## Agent-driven workflow

- Work in small, reviewable stages from planning through launch readiness.
- Keep this plan as the source of truth and use `backlog.md` to track progress.
- Update the backlog as each stage is completed; bring the user in for meaningful direction choices and reviewable milestones.

## Completion criteria

- The site presents the student's profile and projects clearly, including in-progress work where appropriate.
- Main navigation, project links, contact links, and résumé link work.
- Layout is usable across common screen sizes and keyboard navigation.
- The project builds successfully and is ready to deploy as a static site.
